The Transit Map at `/map` renders a schematic diagram of the City Metro demonstration network directly in the browser as an SVG — no tile server, no external map library. Each stop is placed at an exact `(x, y)` coordinate read from `STOPS` in `demo-data.js`, and each line is drawn as a coloured path connecting its ordered stops. A legend of line-toggle buttons lets riders dim individual lines to focus on the routes they care about, while tapping any stop node opens a detail panel listing every line that serves it.

## The `/map` Route

The router registers `/map` and delegates to `renderMap(main)` from the map view module. The function builds the SVG canvas, draws all lines and stops, wires up the toggle legend, and attaches stop-tap handlers — all without a build step or external dependency.

From `js/app.js`:

```js title="js/app.js"
const VIEWS = {
  // …
  '/map': [renderMap, 'Map'],
  // …
};
```

## Line Toggle Legend

The map includes a legend row of buttons, one per line, that let riders show or hide individual lines to reduce visual clutter.

Each button carries an `aria-pressed` attribute. When `aria-pressed="true"` the line is visible; when `aria-pressed="false"` the line's SVG path group receives the `.dim` class, which reduces its opacity through a CSS transition. Pressing the button again removes `.dim` and restores full opacity.

```js
// Toggling a line button (simplified from the map view)
btn.addEventListener('click', () => {
  const pressed = btn.getAttribute('aria-pressed') === 'true';
  btn.setAttribute('aria-pressed', String(!pressed));
  lineGroup.classList.toggle('dim', !pressed);
});
```

This approach keeps the toggle state machine entirely in the DOM — no separate JavaScript state variable is needed — and exposes the current state accessibly to screen readers.

## Stop Detail Display

Tapping a stop node on the map opens a detail panel beneath the canvas. The panel shows:

- The stop name
- Every line that serves this stop (retrieved via `linesAtStop(stopId)`)
- Whether the stop is a hub interchange

```js title="js/trip-service.js"
export const linesAtStop = stopId =>
  LINES.filter(l => l.stops.includes(stopId));
```

For hub stops the panel also shows connecting lines with their colour badges, giving riders at-a-glance transfer information without navigating away from the map.

<Note>
  The map is a generated SVG built from `STOPS` and `LINES` data at runtime. It is not a tile-based geographic map. Coordinates are schematic layout positions only and do not correspond to real-world geography.
</Note>
